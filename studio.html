Lade einen Minecraft-Java-Bauplan hoch. CraftSteps liest die Blockdaten direkt in deinem Browser und erstellt daraus einen privaten, ungeprüften Entwurf.

Die Datei wird nicht auf einen Server hochgeladen. Litematica-Dateien und ältere Schematics werden automatisch erkannt; ältere Formate können ungenaue Blockstates enthalten.

Wähle eine Bauplandatei, um den Import zu starten.
