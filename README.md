# CraftSteps

Minecraft-Bauanleitungs-App mit Materiallisten und visuellen Bauschritten.

**Status:** Die erste Demo-Version v0.1 wird in einem eigenen Feature-Branch als Pull Request vorbereitet. Die produktive Version bleibt bis zur Prüfung getrennt.

CraftSteps ist ein unabhängiges Projekt und nicht mit WBuilds, Mojang oder Microsoft verbunden.
